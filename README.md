# Nexium Wallet v8 — Liquid Glass
**ДЕМО-кошелёк** для Telegram (виртуальные монеты): реальные курсы, обмен, P2P, чеки, запросы платежа, оповещения, поддержка, роли персонала.

## Установка
1. `BOT_TOKEN` — только в переменных Vercel.
2. Vercel → Storage → Upstash Redis → подключить к проекту.
3. Env: `BOT_TOKEN`, `ADMIN_ID` (владелец), `APP_URL=https://проект.vercel.app`, `WEBHOOK_SECRET`. Необязательно: `BOT_USERNAME`, `CRON_SECRET`.
4. Deploy, затем один раз открой `https://проект.vercel.app/api/setup?key=WEBHOOK_SECRET`.
5. BotFather: `/setinline` (плейсхолдер `1 GRAM`).

## Что убрано
Игры (Crash, Mines, Dice, колесо, кейсы), трейдинг, ежедневный кейс, задания, промокоды, стартовый бонус, награды за рефералов, стейкинг, массовая раздача (airdrop). Бесплатных монет в системе больше нет: баланс пополняется только переводами, чеками, P2P и ручной выдачей владельцем (`give`).

## Пользователям
Кошелёк, структура портфеля, переводы с комментарием, **запросы платежа**, чеки (ссылка и inline), обмен, P2P, рынок с избранным и спарклайнами, **ценовые оповещения**, **адресная книга**, история с фильтрами и CSV, **поддержка (тикеты)**, **баг-репорты**, новости, 7 валют отображения, акцентные цвета, скрытие баланса, вибрация.
Команды бота: `/start /rates /balance /news /support /id /ref /help`.

## Роли (вкладка Staff)
| Роль | Доступ |
|---|---|
| Владелец (`ADMIN_ID`) | всё, включая выдачу монет и массовый сброс |
| Администратор | пользователи, баны, рассылка, реклама, тикеты, новости, роли (кроме кодеров/админов), настройки, логи, аудит |
| Модератор | пользователи, баны, тикеты, новости, баги |
| Поддержка | пользователи (просмотр), сообщения, тикеты |
| Кодер | дашборд, настройки и флаги, тех. работы, логи/здоровье системы, баги, аудит |
| Тестировщик | дашборд, баги, логи и здоровье системы |

Роли назначает владелец: Staff → Роли (или карточка пользователя → Роль). Все действия персонала пишутся в журнал аудита.

## Staff-панель
Дашборд · Пользователи (карточка, заметка, бан, сообщение, сброс, смена ID, роль) · Тикеты · Баг-трекер · Новости · Рассылка · Реклама и метки источников · Роли · Настройки (тех. работы, выключатели разделов, комиссия, лимит перевода) · Система (Redis, курсы, вебхук, журнал ошибок) · Аудит.

## Cron
Раз в сутки (`/api/cron`) проверяет ценовые оповещения; также проверяются при заходе в приложение.
