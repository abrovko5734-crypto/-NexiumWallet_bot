# Nexium Wallet v10 — пополнение через Tonkeeper, вывод через @Keldisqq
Кастодиальный кошелёк в Telegram: переводы, обмен, P2P, чеки, запросы платежа, оповещения, поддержка, роли персонала.

## Что нового в v10
- **Пополнение переводом на Tonkeeper.** Пользователь отправляет TON или USDT (сеть TON) на адрес проекта и пишет в комментарии свой ID (`NX…`). Кнопка «Открыть в Tonkeeper» заполняет адрес, сумму и комментарий.
  - **TON** зачисляется автоматически: бэкенд читает входящие транзакции через toncenter, каждая транзакция зачисляется один раз.
  - **USDT** и спорные случаи — заявка «Я перевёл(а)»: персонал проверяет перевод в Tonkeeper и зачисляет (Staff → Пополнения).
  - Переводы без комментария или с неверным ID попадают в «неопознанные» — владелец привязывает их к пользователю.
- **Вывод через @Keldisqq.** «Вывести» → монета, сумма, адрес. Монеты резервируются, создаётся заявка, а кнопка «Написать @Keldisqq» открывает чат с заготовленным сообщением. Админ получает уведомление, платит со своего Tonkeeper и жмёт «Отметить выплаченным» (хеш транзакции необязателен) — пользователю приходит уведомление. Заявку можно отменить, пока она на проверке (монеты возвращаются).
- Адреса последних выводов запоминаются; история пополнений и заявок в приложении.
- Команды бота: `/deposit`, `/withdraw`, `/history`, `/contact`.
- @CryptoBot (Crypto Pay) остаётся **необязательным** вторым способом: счёт на пополнение и автовывод на аккаунт @CryptoBot.

## Запуск
1. Vercel: подключить Upstash Redis. Env: `BOT_TOKEN`, `ADMIN_ID`, `APP_URL`, `WEBHOOK_SECRET`.
2. **`LIVE_MODE=1`** — боевой режим (при первом входе старые виртуальные балансы обнуляются).
3. **`TON_ADDRESS`** — адрес твоего кошелька Tonkeeper (UQ…/EQ…), куда пользователи переводят деньги. Без него перевод на Tonkeeper отключён.
4. Желательно `TONCENTER_KEY` (бесплатный ключ у @tonapibot) — без ключа лимит ~1 запрос/с.
5. `CONTACT_USERNAME=Keldisqq` (по умолчанию уже Keldisqq), `OPERATOR_NAME`, при необходимости `LEGAL_DATE`.
6. Необязательно: `CRYPTOPAY_TOKEN` (+ webhook `https://ПРОЕКТ.vercel.app/api/pay`), `CRYPTOPAY_TESTNET=1`, `GRAM_ASSET`.
7. Deploy → один раз открой `/api/setup?key=WEBHOOK_SECRET` (вебхук, команды, описание).
8. **Частая проверка поступлений.** Vercel Cron на бесплатном тарифе работает раз в сутки, поэтому поставь внешний пинг раз в минуту (например, cron-job.org) на  
   `https://ПРОЕКТ.vercel.app/api/cron?ton=1&key=WEBHOOK_SECRET` — это лёгкий режим, только поступления TON. Также проверка идёт при открытии приложения и по кнопке «Проверить поступление».

## Как работает безопасность
- Зачисление идемпотентно: хеш транзакции помечается `SET NX`, при сбое метка откатывается и транзакция обработается повторно.
- Пыль меньше 0.01 TON не учитывается. Дубли хешей в заявках отклоняются.
- Вывод: списание → заявка → ручная выплата; отмена/отклонение возвращают монеты; дневной лимит, минимум, комиссия настраиваются в Staff → Настройки.
- Все действия персонала пишутся в аудит. Выдача монет без обеспечения и сброс счетов в боевом режиме отключены.

## Проверено / не проверено
Логика (зачисление, дубли, заявки, вывод, отмена, права, команды бота) прогнана на моках: 44 проверки. **В реальной сети не тестировалось:** формат ответа toncenter и deeplink Tonkeeper для USDT (`jetton=`). Сделай тестовый перевод 0.1 TON и пробную заявку на вывод, прежде чем открывать пользователям. Если TON не зачисляется, посмотри Staff → Система → ошибки (`ton_scan`).

## Ответственность оператора
Вы храните деньги пользователей. Обмен по рыночному курсу означает, что обязательства и запасы могут расходиться по монетам: следите за Staff → Выводы → «Платёжеспособность» и балансом Tonkeeper. Документы `/privacy` и `/terms` — шаблон, не юридическая консультация: до запуска покажите их юристу и проверьте требования вашей страны к криптоуслугам, AML/KYC и налогам.
